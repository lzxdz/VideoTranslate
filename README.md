# VideoTranslate Android

Тестовый прототип: английская речь → русский перевод → русская озвучка.

## Конфиденциальность и безопасность

- Приложение не просит доступ к контактам, SMS, файлам, геолокации или камере.
- Разрешение микрофона требуется только для распознавания речи.
- История распознанной речи и переводов не сохраняется в файлы или базу приложения.
- Текст речи не выводится в системные уведомления и не записывается приложением в логи.
- Перевод выполняется локально через Google ML Kit после загрузки модели. API-ключ и пользовательский сервер не нужны.
- Сетевой трафик приложения ограничен HTTPS; открытый HTTP запрещён.
- Android backup для данных приложения отключён.
- Сервис перевода не экспортируется и не предназначен для управления сторонними приложениями.
- Плавающее окно и разрешение SYSTEM_ALERT_WINDOW удалены как ненужные.

## Важное ограничение

Android SpeechRecognizer может передавать аудио выбранной системной службе распознавания; это зависит от устройства, поставщика распознавания и настроек Android. Приложение не может гарантировать, что сторонняя служба никогда не обрабатывает аудио на сервере. Для максимально приватной работы используй распознавание речи, которое поддерживает обработку на устройстве, если оно доступно.

Текущий прототип слушает звук через микрофон, а не захватывает внутренний аудиопоток YouTube. Для проверки включи звук через динамик; наушники могут не подойти. Это debug-сборка, не прошедшая независимый аудит безопасности.

## Сборка

Открой вкладку Actions, выбери успешный запуск и скачай artifact `VideoTranslate-debug-apk`.
