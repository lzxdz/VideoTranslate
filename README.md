# VideoTranslate Android

Тестовый прототип Android-приложения: английская речь -> русский перевод -> русская озвучка.

## Без API-ключа

Перевод выполняется на устройстве через Google ML Kit Translation. Внешний API endpoint, ключ и платная модель не нужны. При первом использовании приложение скачивает языковую модель English/Russian через интернет; после этого сам перевод может работать без сети, если модель уже сохранена.

Распознавание использует системный Android SpeechRecognizer, а озвучивание — системный TextToSpeech. Их доступность и работа зависят от установленных служб и голосовых пакетов Android.

## Ограничения текущего прототипа

- Приложение слушает звук через микрофон, а не захватывает внутренний аудиопоток YouTube. Для проверки включите звук через динамик; наушники могут не подойти.
- Распознавание речи может зависеть от интернет-соединения и выбранного сервиса Android.
- Перевод может иметь задержку, особенно при первой загрузке модели.
- Это debug-сборка для тестирования, не стабильный релиз.

## Сборка

GitHub Actions собирает APK. Откройте вкладку Actions, выберите успешный запуск и скачайте artifact `VideoTranslate-debug-apk`.
