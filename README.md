# VideoTranslate — Offline Whisper build

Отдельная экспериментальная ветка: `offline-whisper-prototype`. Она не заменяет `main`.

## Модели и стоимость

- **Распознавание речи:** Whisper `base.en` через whisper.cpp Android (MIT). Модель загружается один раз при первом запуске из Hugging Face; размер примерно 140–150 МБ.
- **Перевод:** Google ML Kit English → Russian с локально загружаемой моделью перевода; SDK бесплатный, после загрузки перевод выполняется на устройстве.
- **Озвучка:** системный Android TextToSpeech с русским голосом, если он установлен.
- Нет API-ключей, подписки или платного облачного API. Интернет нужен при первом скачивании моделей; после этого распознавание и перевод рассчитаны на работу офлайн.

## Как работает

Приложение пишет звук с микрофона в короткие WAV-фрагменты, распознаёт их Whisper локально, переводит распознанный английский текст локальной моделью ML Kit и озвучивает русский текст. Для сокращения задержки очередь ограничена двумя фрагментами.

**Ограничения прототипа:** задержка зависит от процессора и памяти телефона; шестисекундные фрагменты не гарантируют синхронный перевод в реальном времени. При первом запуске требуется стабильный интернет и достаточно места для модели. На Android 10+ приложение запрашивает системное разрешение на захват внутреннего аудио (MediaProjection) и пытается читать медиапоток напрямую. Если источник запрещает захват или система не поддерживает его, используется микрофон как резервный вариант. Совместимость зависит от Android и политики аудио источника. Русский голос Android может потребовать отдельной загрузки в настройках системы.

## Сборка

GitHub Actions workflow `Offline Whisper APK` собирает отдельный APK. Application ID изменён на `ru.videotranslate.offline`, поэтому эта экспериментальная сборка может устанавливаться рядом с обычной версией.
